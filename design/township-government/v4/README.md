# 第四版：扩大对话区，紧凑辅助区域

根据本轮用户附图重新生成首页 UI 样例。保留原图的左侧导航、欢迎区、对话输入区、四个快捷入口，以及下方“最近会话 / 常用能力”的结构，重点调整空间分配。

## 本轮调整

- **对话为主**：对话输入区明显增高，目标约占全屏高度的 43%–46%，适合输入长任务和粘贴材料。工具栏收在底部，不用额外卡片切碎编辑空间。
- **欢迎区减高**：问候、日期与浅色山水保留，缩小标题与装饰占用，让正文更早进入视线。
- **快捷入口紧凑**：四张卡片保持一排，缩小图标容器、内边距和说明长度，仍保留独立图标和明确名称。
- **下方列表减高**：保留两栏结构，用精简行距、短说明与细分隔线呈现最近会话和常用能力。
- **统一细节**：克制的 10px 级圆角、细边框、清晰中文字体与一致基线；紧凑布局不以缩小可读文字为代价。
- **延续既有能力**：常用能力保留“档案管理 MCP”和“档案审核 Skill”，真实连接仍显示待配置。
