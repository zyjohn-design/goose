# 朱砂政务 · 卡片交互原型

第三轮设计以朱砂政务为例，将卡片、详情内容和相关操作做成可点击的原型。打开 `index.html` 可独立预览；`cards.fragment.html` 为同一版本的可编辑源文件，适合在对话中嵌入预览。此目录没有替换 Electron 的实际业务页面。

## 卡片覆盖

| 页面 | 独立卡片数 | 可查看或体验的内容 |
| --- | ---: | --- |
| 配方中心 | 6 | 每张配方的介绍、办理步骤、参数表单、示例结果；支持收藏与搜索 |
| 技能中心 | 6 | 技能说明、输入与输出、调用示例、原型启停；档案审核可跳转至 MCP 详情 |
| 应用中心 | 6 | 日程展开、文书结构预览、办事指南结构、材料勾选、报表口径和值班交接 |
| 扩展管理 | 7 | 独立配置表单、连接状态说明、工具清单；档案 MCP 的五个工具可逐项展开 |
| 任务调度 | 3 | 任务详情、时间配置、原型暂停或恢复 |
| 会话历史 | 3 | 独立示例对话和关联配方/技能入口 |
| 主题中心 | 1 | 同一朱砂主题的 Light / Dark 即时切换 |
| 设置 | 4 | 个人资料编辑、模型服务说明、工作偏好和关于信息 |

共 36 张独立资源卡片。工作台另有可点击的快捷能力、档案入口、最近会话和常用配方；底部“张主任”可打开账户菜单。点击卡片主体查看详情，点击卡片底部动作可直接进入相应分区，返回或按 Escape 可回到列表。

## 交互与状态

- 搜索、分类和收藏过滤实时更新列表，搜索输入保留焦点。
- 配方参数只形成明确标注的本地模板预览，不调用模型。
- 保存按钮在嵌入预览中直接运行本地交互，避免依赖被预览环境拦截的原生表单提交。
- 材料勾选、表单内容和偏好在当前原型会话内保留。选择的页面、卡片、主题和部分显示状态可由宿主恢复；用户填写的内容和资料不写入模型可见状态。
- 原型不进行网络请求，不接收真实密钥，不修改正式 Goose、系统设置或档案数据，不创建定时任务或发送消息。真实档案服务仍按上一轮约定留待后续配置。
- 布局在宽窗口显示侧栏和卡片网格，窄窗口自动重排。所有卡片都有独立图标和原生按钮入口。

## 已验证

运行 `node design/township-government/v3/check.cjs`（使用 `ui` 的既有 jsdom 开发依赖），检查所有 36 张卡片、详情分区、返回导航、搜索、收藏、模板参数及转义、五项 MCP 工具说明、配置反馈、材料勾选、资料编辑、账户菜单及明暗切换。

另在真实浏览器中检查了卡片列表、配方参数填写与示例结果，以及档案 MCP 的详情/工具分区。所有数据为虚构示例，连接状态没有伪装为已连通。
