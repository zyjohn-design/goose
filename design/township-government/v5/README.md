## 对话界面规则

- 用户消息靠右；助手回答为左侧整宽卡片；工具调用为可折叠卡片，显示结果数与状态。
- 文件卡片统一结构：类型图标（DOCX 蓝、PDF 红、XLSX 绿、图片蓝灰）、文件名、大小与来源、预览 / 下载。
- 点击文件卡片在右侧打开预览抽屉（约 45% 宽），对话区保持可滚动；抽屉标签为预览、批注、版本、信息。
- 外部链接卡显示站点、标题、摘要；打开前提示将离开应用。
- 语音消息显示波形与时长，可展开转写文字。
- 输入框沿用第四版的大尺寸编辑区，附件、图片、语音入口放在底部工具栏。

## 文档管理规则

- 目录：全部、我的、公文草稿、政策文件、会议纪要、档案材料、会话生成、共享给我、回收站。
- 来源标签区分对话生成、本地上传、档案 MCP；状态标签为草稿、审核中、已归档。
- 列表与卡片视图共享筛选条件；选中文件后右侧显示详情、版本记录与审核 / 归档操作。
- 发起审核对接档案审核 Skill，归档写入档案管理 MCP；服务未配置时按钮显示“待配置”。
- 密级与权限由服务端校验，界面只做展示。
