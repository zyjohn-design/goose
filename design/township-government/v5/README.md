## 可点击原型 `prototype.html`

单文件离线运行，无外部请求。左侧底部可切换三套主题与 Light / Dark。

- 点击任意文件卡片、引用编号或右侧“本次引用”，打开预览抽屉；Word / PDF 按页显示，Excel 显示表格。
- 抽屉内可切换预览、批注、版本、信息；点击正文黄色标记跳到对应批注；支持缩放和缩略页切换。
- 点击图片打开大图浏览；语音可播放（波形动画）并展开转写；MCP 工具卡可展开查看结果。
- 外部链接先弹出离开应用提示；下载、分享、语音录制为提示占位。
- 输入框支持 Enter 发送、Shift+Enter 换行，可添加示例附件；发送后显示模拟回复，不调用模型。

## 对话界面规则

- 用户消息靠右；助手回答为左侧整宽卡片；工具调用为可折叠卡片，显示结果数与状态。
- 文件卡片统一结构：类型图标（DOCX 蓝、PDF 红、XLSX 绿、图片蓝灰）、文件名、大小与来源、预览 / 下载。
- 点击文件卡片在右侧打开预览抽屉（约 45% 宽），对话区保持可滚动；抽屉标签为预览、批注、版本、信息。
- 外部链接卡显示站点、标题、摘要；打开前提示将离开应用。
- 语音消息显示波形与时长，可展开转写文字。
- 输入框沿用第四版的大尺寸编辑区，附件、图片、语音入口放在底部工具栏。

## 文档管理规则

- 目录：全部、我的、公文草稿、政策文件、会议纪要、档案材料、会话生成、共享给我、回收站。
- 来源标签区分对话生成、本地上传、档案 MCP；状态标签为草稿、审核中、已归档。
- 列表与卡片视图共享筛选条件；选中文件后右侧显示详情、版本记录与审核 / 归档操作。
- 发起审核对接档案审核 Skill，归档写入档案管理 MCP；服务未配置时按钮显示“待配置”。
- 密级与权限由服务端校验，界面只做展示。

图片为 AI 生成的视觉参考，文字与细节以本说明为准；示例文件、人员和数据均为虚构。

## 文档管理交互原型

[documents.html](documents.html) 可离线打开，支持 `?theme=navy&mode=dark&doc=3` 这类参数。包含：

- 左侧目录树（我的文档、共享给我、各科室、档案库）和存储空间。
- 搜索（标题、文号、标签，⌘K 聚焦）、类型标签、部门、密级、时间、状态筛选，以及共计数量和清除筛选。
- 列表和卡片两种视图，都能点击打开右侧详情面板。详情包括文号、状态、密级、负责人、标签、关联会话、档案号和版本流转记录。
- 草稿和已退回的文件可以发起审核。弹窗先由档案审核 Skill 预检（材料完整性、格式规范、密级标注、敏感信息），预检完成后才能提交；之后选择审核人、审核方式并填写送审意见。提交后状态改为“审核中”，并弹出提示。审核中的文件可以撤回。
- 已审核的文件可以归档：选保管期限和档案盒号，状态改为“已归档”并写入档号。
- 上传：可点击按钮选择文件，也可以拖入页面，显示进度条，完成后加入“我的文档”。
- 侧栏切换三套主题和明暗，可跳转到对话原型；对话原型里的“文档管理”和预览抽屉里的“在文档管理中打开”也会回到这里，并带上当前主题。
