# 政务智办 · 镇政府版 UI 设计包（v6）

本设计包包含三套政务主题的完整界面设计稿，每套主题都有浅色和深色两种模式，每种模式 9 个页面，共 54 张图（1600×1000）。

- `index.html`：设计稿总览，双击即可在浏览器打开，点击缩略图查看大图。
- `政务智办-UI设计稿.pdf`：全部设计稿合集，适合直接转发或打印。
- `images/<主题>/<模式>/NN-页面.png`：单张原图。
- `themes/*.json`：三套主题的主题包文件，界面上所有颜色都取自这些文件，在桌面端「主题中心 → 导入主题包」可直接使用。
- `kit.html`：设计稿渲染页，`kit.html?theme=navy&mode=dark&screen=chat` 可切换主题、模式和页面。

## 用户权限管理对接方案（设计阶段）

目标是让本系统接入镇里已有的统一身份认证、政务钉钉、浙政钉或 OA 等系统，复用它们的账号和组织架构，同时把“能做什么”留在本系统内部管理，便于审计和收权。

**职责划分。** 外部系统负责“谁能登录、属于哪个部门、担任什么职务”；本系统负责“这个角色能用哪些功能、看哪些数据、到什么密级”。外部系统只决定用户属于哪个角色，不直接下发权限点。外部系统换了或停了，本地权限配置不受影响。

**对接方式。** 按适配器接入，同一时间可启用多个身份源：

| 方式 | 用途 |
| --- | --- |
| OIDC / OAuth 2.0 | 单点登录，适合统一身份认证平台、政务钉钉、浙政钉 |
| SAML 2.0 | 单点登录，适合已有 SAML 的老平台 |
| CAS | 单点登录，适合高校或部分地方政务平台 |
| LDAP / AD | 账号校验与组织同步 |
| SCIM 2.0 或定时 API 同步 | 用户、部门、岗位的增量同步；离职人员自动停用 |

**映射规则。** 规则按优先级从上到下匹配，条件可以组合：所属部门、职务、外部角色或用户组、用户属性（如“是否档案员”）。命中后授予一个或多个本地角色，并带上数据范围（全镇、本部门、本村）。同步来的角色在界面上标注“同步”，手动授予的标注“手动”，规则变更前可以预览影响到哪些人。

**权限模型。** 采用“角色 + 密级 + 数据范围”三层控制：

- 角色决定功能权限，例如发起对话、查看文档、上传编辑、发起审核、审批、归档、档案库查询、秘密级访问、技能管理、扩展管理、用户与权限。
- 密级决定能看哪一级文件（公开、内部、秘密），秘密级必须单独授权。
- 数据范围决定能看哪些部门或村的数据。
- 技能、扩展和 MCP 也按角色授权，例如只有档案管理员能用“档案审核”技能和人事档案库。

**临时授权。** 可以给个人授予有到期时间的临时权限（例如“至 10 月 31 日可访问党委会议纪要”），到期自动收回，并记录授予人和原因。

**兜底与安全。** 保留至少一个本地管理员账号，外部身份源故障时仍可登录处理问题。外部同步默认不能授予“用户与权限”管理权限，这一权限只能在本地手动授予。所有登录、同步、角色和权限变更都写入审计日志，可按人、时间、类型查询和导出。

**后续实现顺序（建议）：** 先做 OIDC 单点登录和本地角色矩阵；再做组织同步和映射规则；最后做临时授权、审计导出和多身份源。具体对接哪一个外部系统，需要客户提供平台名称和接口文档。
